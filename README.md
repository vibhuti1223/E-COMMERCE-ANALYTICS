# E-Commerce Sales Analytics Dashboard

## Overview
End-to-end business analytics project analyzing 793,000+ real e-commerce transactions
to uncover revenue trends, top markets, and best-performing products.

## Business Insights
- Total Revenue: £17,324,932
- Total Orders: 36,457
- Total Customers: 5,860
- Average Order Value: £475.22
- Peak Revenue Month: November 2010
- Top Market: United Kingdom

## What I Did
- Cleaned and processed 1M+ row dataset using Python (pandas) — handled nulls,
  removed cancellations, filtered invalid records down to 793K clean rows
- Performed exploratory data analysis to answer key business questions
- Built 4 visualizations: monthly revenue trend, top countries, best-selling
  products, top revenue products
- Exported findings into a formatted Excel dashboard with 4 sheets for
  non-technical stakeholders

## Tech Stack
Python, pandas, NumPy, Matplotlib, Seaborn, openpyxl, Excel
